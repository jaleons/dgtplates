# dgtplates

Este proyecto para el análisis de las matriculaciones de vehículos en España se compone de tres módulos

1.- Carga del fichero diario de matriculaciones desde la web de la DGT. Este proceso se ejecutaría diariamente leyendo el último fichero publicado o el día posterior al último día cargado en la base de datos
2.- Inclusión de los datos del fichero en BD tabla de matriculaciones (aún pendiente de definir y crear)
3.- Presentación de datos estadísticos con capacidad de establecer filtros y diferentes criterios

A futuro podríamos plantear crear previsiones usando librerías de Machine Learning (python)
